# Micronaut Security

[English](README.md) | [简体中文](README.zh-CN.md)

An adapter for common authentication and authorization annotations, imperative authentication providers, and request security context from Micronaut Security 5.3.2. [module.norm](micronaut/security/module.norm) defines the package. The complete Java API census and reasons for unsupported APIs are in the NAR's `binding/java-api.json`.

[Samples](samples/README.md) compare allowed and rejected anonymous HTTP requests.
