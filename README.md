# Micronaut Security

[English](README.md) | [简体中文](README.zh-CN.md)

An adapter for common authentication and authorization annotations, imperative authentication providers, and request security context from Micronaut Security 5.3.2, published as `micronaut:security:1`. The complete Java API census and reasons for unsupported APIs are in the NAR's `binding/java-api.json`.
